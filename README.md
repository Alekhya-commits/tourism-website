# Tourism Website

A simple, responsive tourism website built with HTML, CSS, Bootstrap, and JavaScript.

## Overview

This project showcases popular travel destinations in India using interactive destination cards and detailed view sections. Users can navigate between the home screen, a favorites section, and detailed destination pages using a clean single-page experience.

## Features

- Responsive design with Bootstrap
- Static HTML/CSS/JS website
- Interactive destination cards
- Detailed destination views with image and text content
- Simple navigation using JavaScript section display logic

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap 4
- GitHub Pages (for deployment)

## Files

- `tourism.html` — main website page
- `style.css` — styling for layout and responsiveness
- `script.js` — navigation logic for showing and hiding sections
- `assets/` — local image assets used by the site

## How to run locally

1. Open `tourism.html` in a browser.
2. Or use a local development server to preview the site.

## How to deploy on GitHub Pages

1. Create a GitHub repository.
2. Push this project to the repository.
3. In GitHub repository settings, enable GitHub Pages from the `main` branch and root folder.
4. Visit the provided GitHub Pages URL.

## Notes

This is a static web project ideal for learning and portfolio use.
